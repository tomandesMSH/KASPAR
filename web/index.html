Windows crossed a line

Ads in the Start menu. Bing opening when you just wanted to launch an app. A right-click menu that hides half its options behind an extra click.

None of it was asked for, and most of it is a setting Windows already has. Microsoft just doesn't give you a button for it. KASPAR does.

Tomáš Vaněk, who started KASPAR as a personal collection of fixes

15 tweaks, nothing hidden

Each one writes values Windows already reads. Pick a tweak to see exactly what it changes and what Revert puts back.

From download to done in a minute

KASPAR applies every tweak itself. There are no scripts to download and no Python or PowerShell to set up.

KASPAR-win-Setup.exe78 MB

01Install

Run the installer from GitHub Releases, or unzip the portable build. KASPAR asks for administrator rights when it starts.

Restore pointRestore point created successfully.

02Make a restore point

One button in the top bar creates a System Restore point before you change anything.

Revert (3)Run tweaks (3)

03Pick and run

Tick the tweaks you want and press Run. Changed your mind later? Select the same tweaks and press Revert.

Reversible

Registry tweaks put back the Windows default value, or delete the value if Windows had none.

Updates itself

The only thing KASPAR connects to is GitHub, to check for a new release.

Open source

Written in C# with WinUI 3 and released under the MIT license. Read every line on GitHub.
