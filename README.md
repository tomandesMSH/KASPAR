## ℹ️About Kaspar

Kaspar is a powerful Windows utility that gives you access to hidden and normally inaccessible system settings. 
It allows advanced users to tweak Windows behavior safely, like modifying registry keys, and other system options that are not normally exposed via the standard interface.

## ⭐Features

- Modify Windows settings that are normally hidden or hard to reach.
- Rewriting registry keys for you.
- Option to reverse the effect (Reverting tweaks).

## 🛠️Requirements

- Windows 10 or later.
- Python 3.x

To build or run KASPAR from source, you'll also need the [.NET SDK](https://dotnet.microsoft.com/download) (KASPAR's app shell is a native [WinUI 3](https://learn.microsoft.com/windows/apps/winui/winui3/) app).

## ❓How to use

**End users**: download and run the installer (`KASPAR-win-Setup.exe`) from the [Releases](https://github.com/tomandesMSH/KASPAR/releases) page, then choose which script you would like to run.

**Developers**: clone the repository, then from `src/KASPAR/` run:

```
dotnet run
```
